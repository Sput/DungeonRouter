# Rules Router

An experimental, open-source D&D 5e (2014) rules assistant demonstrating cost-aware routing across `gpt-5-nano`, `gpt-5-mini`, and `gpt-5` with NVIDIA NeMo Switchyard.

See [the project plan](docs/project-plan.md) for the proposed architecture, scope, and one-week implementation schedule.
